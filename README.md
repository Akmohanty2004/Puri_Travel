# PuriTravel — Plan. Book. Explore. 🌅🌊✈️

An ultra-modern, responsive travel booking and spiritual pilgrimage platform built with **React 19**, **Vite**, **Tailwind CSS**, and **Lucide Icons**. Designed around the exact color palette, symbols, and motifs of the official **PuriTravel** logo (Jagannath Temple Royal Navy, Bay of Bengal Azure Waves, and Sunrise Flame Orange).

---

## 🎨 Brand Design & Color Palette

- **Primary Temple Navy**: `#071e3d` & `#0b2545` (Symbolizing Lord Jagannath's timeless sanctity)
- **Ocean Wave & Azure Blues**: `#0077b6`, `#0096c7`, `#00b4d8` (Bay of Bengal waves & Blue Flag Golden Beach)
- **Sunrise Flame Orange & Sun Gold**: `#ff6f00`, `#ff7b00`, `#ff9e00`, `#ffbe0b` (Puri sunrise, holy lamp flames, and the logo's flying paper airplane)
- **Pristine Sands**: `#f8fafc`, `#ffffff`, `#fffbf2`

## 🚀 Key Features

### 1. 🌟 Creative & Unique Animations
- **Floating Round Animated Social Media Wheel (Bottom-Right Dock)**:
  - Satellite planetary social nodes (WhatsApp Concierge, Instagram Stories, YouTube 4K Vlogs, 24/7 Helpline) continuously orbit a central glowing core with counter-rotation.
  - Expands into an interactive quick-connect concierge modal with 1-click WhatsApp chat.
- **PuriTravel 360° Social Orbit Section**:
  - Interactive circular planetary dial allowing devotees and tourists to rotate between live temple Mangala Alati reels, Golden Beach sunrise clips, and Chilika dolphin safaris.
- **Gliding Orange Paper Plane Animation**:
  - Echoing the orange paper plane in the logo, a smooth-gliding airplane floats across an arched gold trajectory in the hero section.
- **Pulsing Golden Sun Halo & Coastal Wave Dividers**:
  - Seamless SVG wave crests echoing the curling blue wave from the logo.

### 2. ⚡ Live Coastal & Temple Pulse Tracker
- **Shree Jagannath Mandir Live Status**: Queue wait times, crowd density meter, and fresh Mahaprasad arrival timings at Anand Bazar.
- **Blue Flag Golden Beach Tides**: Next sunrise countdown, wave heights, and lifeguard safety status.
- **Chilika Lagoon Dolphin Probability Index**: Real-time dolphin spotting chance (e.g. 92% today) and Satapada speedboat status.

### 3. 📅 Interactive Custom Itinerary Builder
- Visitors can choose their duration (1 Day, 2 Days, 3 Days, 5 Days) and click on sacred or coastal activities to dynamically calculate costs, time slots, and bundle discounts.
- Includes a direct **"Book This Custom Itinerary"** button.

### 4. 🎫 End-to-End Booking Management System
- **5-Step Booking Checkout Wizard**:
  - **Step 1**: Schedule date & devotee group selection (Adults & Children).
  - **Step 2**: Devotee contact information with Senior Citizen wheelchair assistance and optional Temple Puja Gotra.
  - **Step 3**: Optional authentic add-ons (Mahaprasad Bento Box, Personal Sevayat Priest escort, Station AC Cab pickup).
  - **Step 4**: Payment simulation (Instant UPI QR, Debit/Credit Card, Pay 20% Advance).
  - **Step 5**: Confetti celebration (`canvas-confetti`) + printable electronic boarding pass with QR code and unique reference ID (e.g., `PT-2026-8942`).
- **"My Bookings" Manager Drawer**:
  - Persistent storage via `localStorage`.
  - Active reservation badge in the top navigation.
  - Ticket reprint, free cancellation option, and direct WhatsApp concierge support.

### 5. 🏨 Luxury Beachfront Resorts & Heritage Stays
- Featured partner resorts (Mayfair Waves, Sterling Golden Sands, The Chariot Resort, Toshali Sands) with instant room reservation.

### 6. 🛕 Devotees & Pilgrim Etiquette Guide
- Mandatory dress code checklist, mobile/leather locker policy, Anand Bazar Mahaprasad guidelines, and accredited Sevayat advantages.

## 💻 Running the Project Locally

```bash
# 1. Install dependencies (already completed)
npm install

# 2. Run the development server
npm run dev

# 3. Build for production
npm run build
```

Development server runs at: `http://localhost:5173/`
